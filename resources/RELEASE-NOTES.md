Первая версия DoIT для Windows 10/11 x64.

## Скачать и запустить

В разделе **Assets** скачайте **DoIT-0.1.0-Windows-x64.zip**, распакуйте **весь архив** в отдельную папку и запустите **DoIT.exe**. Node.js устанавливать не требуется. Архивы **Source code** содержат исходники, а не готовое приложение.

При первом запуске выберите пустое пространство или демонстрационные записи.

## Возможности

- Задачи, подзадачи, приоритеты, проекты и быстрый ввод.
- Мой день, месячный календарь, таблица задач с фильтрами.
- Цели, заметки, идеи, закрепление и общий поиск.
- Вложения и ZIP-копии с восстановлением записей и документов.
- Погода по выбранному городу через Open-Meteo; нужен интернет.

Данные хранятся локально в `%APPDATA%\DoIT`. Регистрация не нужна. `Ctrl+N` — новая задача, `Ctrl+K` — поиск.

Это предварительная версия без цифровой подписи: Windows может показать предупреждение о неизвестном издателе. Синхронизации, повторяющихся задач и системных напоминаний пока нет. Резервные копии не зашифрованы.

Публикация выполняется GitHub Actions после проверки интерфейса, SQLite и упакованного приложения на Windows. Прогноз погоды в тестах использует тестовые ответы API.
