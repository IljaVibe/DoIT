## DoIT 0.2.0 для Windows 10/11 x64

Скачайте **DoIT-Setup-0.2.0-x64.exe** и запустите обычный мастер установки. Архивы и BAT-файлы не нужны. Установка не требует интернета.

### Новое

- Локальные аккаунты с паролем; шифрование базы и вложений.
- Зашифрованные копии .doit: ручное сохранение, автоматическое обновление в выбранной папке, восстановление аккаунта на другом компьютере.
- Пять тем: Шалфей, Песок, Туман, Лаванда и Графит.
- Настраиваемый автозапуск Windows и закрытие в трей.
- Перемещаемые окна-виджеты задач, целей и заметки; необязательное закрепление поверх окон.
- Установщик с ярлыками и деинсталлятором. Удаление приложения сохраняет данные аккаунтов.

Данные версии 0.1 доступны через «Продолжить без аккаунта». При создании аккаунта их можно скопировать; исходные гостевые данные остаются на устройстве без шифрования.

Для сохранности после переустановки Windows выберите папку копий в OneDrive или другом облачном диске и дождитесь его синхронизации. DoIT не проверяет загрузку файлов в облако. Для восстановления нужны файл .doit и ваш пароль; сброса через почту нет.

Вариант с локальным аккаунтом бесплатен. Облачный диск предоставляет собственный объём хранения и тарифы. Онлайн-синхронизация между устройствами не реализована.

Проверены хранение и шифрование, гостевые копии, регистрация, вход и восстановление, темы и три виджета в Linux Electron. Сам мастер установки, автозапуск и трей на настоящей Windows в этой среде не проверены. Сборка без цифровой подписи; Windows может показать предупреждение об неизвестном издателе.
