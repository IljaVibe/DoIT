DoIT 0.1.0 — личное пространство для задач и мыслей

Windows 10/11, x64

1. Распакуйте всю папку из ZIP.
2. Запустите DoIT.exe. Устанавливать Node.js не нужно.
3. Выберите пустое пространство или примеры.

Это первая неподписанная сборка. Windows может показать предупреждение
о неизвестном издателе. Запуск на настоящей Windows пока не проверен.

Ctrl+N — новая задача. Ctrl+K — поиск. Esc — закрыть редактор.

Данные: %APPDATA%\DoIT
Резервные копии с документами: Настройки → Сохранить копию.
Копии не зашифрованы. Данные хранятся локально, синхронизации пока нет.

Погода: Настройки → Погода → Найти город. Нужен интернет.

Не переносите DoIT.exe отдельно от остальных файлов приложения.
Перед обновлением сохраняйте резервную копию.
